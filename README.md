We are building a local-first transcript refinery that takes your raw daily voice-journal transcript, automatically applies your standing context and editorial rules, sends it to Claude, and gives you a clean journal entry plus any ambiguities, ready to save as Markdown.

This is not a journaling platform. It is not a second-brain app. It is not a note-taking suite. It is not a generic AI writer. It is not a life dashboard. It is not a cloud social thing. It is not an “AI agent.”

You should be able to: paste or upload a transcript, choose a context pack, choose a prompt profile, hit “Refine,” see the polished journal entry, see ambiguities if there are any, save/export the result as Markdown.
